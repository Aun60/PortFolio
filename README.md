# Portfolio — Aun Ali Kazi

Static site, no build step required. Files:
- index.html
- style.css
- script.js

## Deploy on Vercel
1. Push this folder to a GitHub repo (or drag-and-drop the folder into vercel.com/new).
2. Framework preset: "Other" / static — no build command needed.
3. Deploy.

## Deploy on Render
1. New → Static Site → connect repo (or upload).
2. Build command: leave blank.
3. Publish directory: `.`

## Before you deploy — placeholders to replace
In `index.html`, contact section near the bottom:
- Swap `youremail@example.com` for your real email.
- Swap the two `#` hrefs for your real LinkedIn and GitHub URLs.
